# Omphemetse Prince Molubi — Portfolio Website

A single-file, fully responsive portfolio site (`index.html`) built with plain HTML/CSS/JS — no build step required.

## What's inside
- `index.html` — the entire site (structure, styling, and interactivity in one file)
- `assets/omphemetseprince_resume.pdf` — downloadable CV, linked from the "Download CV" button

## Run it locally
Just open `index.html` in a browser, or serve it:
```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
